# TUNED

Windows installer downloads and updates for TUNED desktop.

[Download the latest release](https://github.com/australis-ordered/tuned-releases/releases/latest)

Install version 0.9.5 once to enable in-app updates. Future published versions appear through **Update now** in TUNED, with download progress and **Restart now** when ready.

This repository contains release downloads. GitHub sign-in is not required to download or update the app.
